# NEXUS EUKB v1

Synthetic enterprise knowledge corpus for the NEXUS retrieval platform.

## Canonical corpus

The committed `data/full/` corpus contains:

- **50,000** source documents
- **402,861** search-ready chunks
- **5,000** labelled evaluation queries
- **11** enterprise domains
- GLOBAL, IN, UK, IE, US, SG and AU scopes

Files:

- `documents.jsonl.gz`
- `chunks.jsonl.gz`
- `evaluation_queries.jsonl.gz`
- `manifest.json`
- `taxonomy.json`
- `synonyms.json`
- `validation_report.json`

The corpus models **Northstar Digital Services**, a fictional multinational technology-services company. No confidential data from a real organisation is included.

## Retrieval challenges represented

- exact identifiers and error codes
- semantic paraphrases with weak lexical overlap
- acronyms and synonyms
- misspellings/fuzzy queries
- ambiguous requests
- multi-condition queries
- active vs archived policy/version conflicts
- country-specific rules
- confidential/ACL-sensitive knowledge
- cross-domain requests

## Ground truth

Evaluation judgments use:

- `3` — highly relevant/intended result
- `2` — relevant alternative
- `0` — deliberately stale/non-relevant version

## Reproduce

```bash
python tools/generate_eukb.py --output data/full --documents 50000 --eval-queries 5000
```

The generator uses seed `20260923` and deterministic gzip output. The `Materialize EUKB Dataset` workflow validates the corpus shape and commits changes only when the generated bytes actually differ.

Recommended retrieval metrics: Precision@K, Recall@K, MRR, MAP, nDCG@K, hit rate and p50/p95/p99 latency.
