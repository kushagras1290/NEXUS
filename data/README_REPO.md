# EUKB dataset in this repository

The tracked files in `data/` are the corpus manifest, taxonomy, synonym dictionary, integrity report and human-readable samples. The deterministic generator in `tools/generate_eukb.py` creates the complete corpus.

The full generated v1 archive contains 50,000 source documents, 402,861 chunks and 5,000 labelled evaluation queries. Keep large generated files out of normal Git history unless Git LFS or a release/object-store workflow is intentionally configured.
